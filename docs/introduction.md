# Введение

Vite-плагин, который собирает шаблоны для серверного рендеринга из компонентов Vue (SFC). Шаблоны пишутся на Vue с типизированными props, а на выходе получаются шаблоны для шаблонизатора сервера (Handlebars, askama или Jinja — см. [Шаблонизаторы](./engines)) и статика с хешами в именах. Сервер ничего не знает о Vite: он рендерит шаблоны и раздаёт статику.

vitempl работает только с Vite: страницы проходят штатную обработку HTML в Vite (хук `transformIndexHtml`, подстановка собранных скриптов и стилей), которой нет в Rolldown без Vite.

## Подключение

```ts [vite.config.ts]
import { defineConfig } from "vite";
import vitempl from "vitempl";
import { handlebars } from "vitempl/handlebars";

export default defineConfig({
  plugins: [vitempl({ engine: handlebars() })],
  build: { outDir: "dist/public" },
});
```

Шаблоны записываются в `dist/templates`, статика — в `dist/public`. Опции плагина — на странице [Сборка](./build#опции).

## Виды шаблонов

| Вид      | Где по умолчанию | Что это                                                       | Вход сборки | Обработка Vite |
| -------- | ---------------- | ------------------------------------------------------------- | ----------- | -------------- |
| Shell    | `index.html`     | `<html>`, `<head>`, общие скрипты и стили, место для страницы | —           | со страницей   |
| Страница | `src/pages/`     | содержимое страницы, рендерится в ответ на обычный запрос     | да          | да             |
| Фрагмент | `src/fragments/` | кусок HTML для ответа на запрос htmx                          | да          | нет            |
| Layout   | `src/layouts/`   | каркас страницы: шапка, подвал, слот для содержимого          | нет         | нет            |
| Partial  | `src/partials/`  | переиспользуемый компонент                                    | нет         | нет            |

Страницы, фрагменты, layouts и partials — компоненты Vue (`.vue`). Layouts и partials попадают в сборку, только если их импортирует страница или фрагмент — напрямую или через другие компоненты. Имя собранного шаблона — путь от `src/` без расширения (`partials/AppHeader`), под этим именем его регистрирует сервер.

Shell не компилируется: он написан на языке шаблонизатора (`<title>{{ title }}</title>`) и получает данные страницы.

## Ассеты

- В shell и страницах ссылки на скрипты, стили и картинки обрабатывает Vite: подставляет собранные файлы с хешами. Ссылки в shell пишутся от корня проекта: `/src/main.ts`.
- В layouts, partials и фрагментах Vite ссылки не обрабатывает: в них можно ссылаться только на файлы из `public/`, например `/icons.svg`.

## Стили

Блок `<style>` в шаблоне обрабатывает Vite, как обычный CSS: с вложенностью, префиксами и минификацией. Стили — обычные модули в графе Vite, поэтому файлы он раскладывает сам:

- стили страницы и её компонентов подключаются в `<head>` этой страницы;
- если компонент используют несколько страниц, его стили попадают в общий файл, и страницы подключают один и тот же файл, без дублирования;
- страница, которая компонент не использует, его стилей не получает.

`<style scoped>` и `<style module>` не поддерживаются: они требуют разметки классами, которую добавляет рантайм Vue.

Ссылки на стили расставляются по страницам, а у фрагментов своего документа нет. Если компонент используется и на странице, и во фрагменте, его стили приходят со страницей: фрагмент подменяет часть уже открытой страницы, стили к этому моменту загружены. Если же шаблон со стилями не используется ни на одной странице, сборка выдаёт предупреждение — такие стили нужно либо задействовать на странице, либо вынести в общий CSS.

## Экранирование

`{{ value }}` и привязанные атрибуты экранируют HTML — как во Vue. Вывод HTML без экранирования (`v-html`) не поддерживается. Экранирует сам шаблонизатор, поэтому у каждого свои условия — см. [Шаблонизаторы](./engines).
